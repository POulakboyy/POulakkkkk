# Reels — 3 scripts

> Vertical 9:16, 20 à 35 s, sous-titres incrustés dans la zone sûre centrale (éviter le tiers bas,
> occupé par la légende et les boutons). Son : voix seule ou nappe très discrète ; si un son
> tendance est utilisé, vérifier ses droits pour un compte qui fait la promotion d'un produit.
> Le Reel 1 est une version resserrée du Short 1 ([`../youtube/shorts.md`](../youtube/shorts.md)).
> Couverture : 1080 × 1920, titre lisible une fois recadré en vignette de grille.

## Reel 1 — Le temps entre deux réunions

**Durée** : 25–30 s · **Fonction** : buffers (C7) · **Source** : Leroy (2009)

| Temps   | Image                                                   | Voix / texte                                                               |
| ------- | ------------------------------------------------------- | -------------------------------------------------------------------------- |
| 0–2 s   | Visage, plan serré.                                     | « Ta réunion finit à 14 h. La suivante commence à 14 h. »                  |
| 2–6 s   | Deux fenêtres de visio qui se remplacent.               | « Ta tête, elle, est restée dans la première. »                            |
| 6–13 s  | Texte serif sur papier : « résidu attentionnel ».       | « Une chercheuse appelle ça le résidu attentionnel. Leroy, 2009. »         |
| 13–24 s | Capture POuxis : un espace se pose entre deux réunions. | « Alors mon agenda laisse un espace entre les deux. Tu choisis sa durée. » |
| 24–28 s | Visage, une seconde de silence.                         | « Le temps entre les choses, c'est pas du temps perdu. »                   |

## Reel 2 — Une phrase, une journée

**Durée** : 20–25 s · **Fonctions** : langage naturel (C4), routage (C5) · Aucune source
scientifique citée : c'est une démonstration.

| Temps   | Image                                                                           | Voix / texte                                                     |
| ------- | ------------------------------------------------------------------------------- | ---------------------------------------------------------------- |
| 0–2 s   | Écran : champ de saisie vide, curseur.                                          | Texte : « huit mots. »                                           |
| 2–8 s   | Frappe réelle : « Réunion projet mardi 14h-16h ». Fragments reconnus surlignés. | Voix : « J'écris une phrase. »                                   |
| 8–15 s  | L'événement apparaît dans la semaine ; des tâches se placent autour.            | Voix : « L'événement est créé. Les tâches trouvent leur place. » |
| 15–20 s | Toucher une tâche : la raison du placement s'affiche en une ligne.              | Voix : « Et à chaque fois, l'app te dit pourquoi. »              |
| 20–24 s | Vue du jour aérée, point corail sur la tâche en cours.                          | Texte : « le reste de ta journée t'appartient. »                 |

> Tourner en capture d'écran réelle à vitesse 1×. Pas d'accélération qui ferait croire à une
> rapidité que l'app n'a pas.

## Reel 3 — Mode avion

**Durée** : 25–30 s · **Fonctions** : hors-ligne (C1), synchronisation chiffrée (C26)

| Temps   | Image                                                             | Voix / texte                                                             |
| ------- | ----------------------------------------------------------------- | ------------------------------------------------------------------------ |
| 0–3 s   | Pouce qui active le mode avion.                                   | Texte : « j'ai coupé le réseau. »                                        |
| 3–10 s  | L'app s'ouvre, on ajoute une tâche, on en coche une. Tout répond. | Voix : « L'app continue. Parce que tes données sont sur ton téléphone. » |
| 10–16 s | Ordinateur à côté, même compte, une autre modification.           | Voix : « Sur l'ordi, je change autre chose. »                            |
| 16–22 s | Mode avion coupé : les deux écrans convergent.                    | Voix : « Je rallume. Les deux se mettent d'accord. »                     |
| 22–28 s | Schéma : téléphone ⇄ relais (cadenas) ⇄ ordinateur.               | Voix : « Et le serveur au milieu ne peut rien lire. Tout part chiffré. » |
| 28–30 s | Papier, point corail.                                             | Texte : « à toi. vraiment. »                                             |

> Si les deux appareils modifient le **même champ**, la règle est « le dernier écrivain gagne »
> (ADR 0002) : ne pas montrer ce cas en le présentant comme une fusion des deux textes.
