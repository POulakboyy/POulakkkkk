# Story du jour J — 7 écrans

> 1080 × 1920, modèle `docs/brand/assets/social-story-1080x1920.svg` (fond sombre chaud, texte
> dans la zone sûre y 250–1670). Une phrase par écran. Publier le matin du jour J, après la mise
> en ligne effective du dépôt et de la liste d'attente. Garder ensuite la série en Story à la une
> « POuxis ».

| #   | Visuel                                                                                           | Texte                                       | Élément interactif                              |
| --- | ------------------------------------------------------------------------------------------------ | ------------------------------------------- | ----------------------------------------------- |
| 1   | Fond encre. Le trait du « P » se dessine, puis le point corail se pose (animation du logo, 3 s). | aujourd'hui, je l'ouvre.                    | —                                               |

| 3   | Capture : la saisie « Réunion projet mardi 14h-16h » qui devient un événement (vidéo 5 s).       | une phrase. la journée se range.            | —                                               |
| 4   | Capture : mode avion activé, l'app répond.                                                       | sans réseau. sans compte. sur ton appareil. | —                                               |
| 5   | Capture : page GitHub du dépôt.                                                                  | le code est ouvert. tu peux tout lire.      | Lien `{{GITHUB_URL}}` — « Voir le code »        |
| 6   | Papier, une ligne serif.                                                                         | c'est pas fini. je veux le finir avec toi.  | Sondage : « Tu testerais ? » Oui / Plus tard    |

Notes :

- **Écran 4** : « sans compte » renvoie à C2 et « sur ton appareil » à C1 ; retirer ces mots si
  les cases du registre ne sont pas cochées.
- **Écran 6** : le sondage sert à mesurer l'intérêt (réponses lues, pas publiées comme chiffre de
  réussite). Pas de compte à rebours, pas de « dernière chance » : rien n'est rare ici.
- **Libellés des liens** : verbe + objet (« Voir le code », « Rejoindre la bêta »), jamais « Clique
  ici ».
- **Accessibilité** : texte affiché ≥ 48 px, contraste papier sur encre ; ne pas compter sur le
  son pour comprendre un écran.
