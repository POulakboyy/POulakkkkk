# `@pouxis/core/tasks`

Pure task engine. Every function is side-effect free; changes are returned as `TaskPatch`
objects to pass to `store.update('tasks', id, patch)` (a key set to `undefined` clears it).

| Feature           | API                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 2.1 Dependencies  | `actionable(tasks)`, `isActionable(task, byId)`, `blockers(task, byId)`, `topoOrder(tasks)`, `detectCycles(tasks)`, `wouldCreateCycle(tasks, fromId, toId)`, `unlockedBy(doneId, tasks)` — done, archived or missing dependencies count as resolved; graph walks are iterative.                                                                                                                                                                                                                                     |
| 2.2 Decomposition | `Decomposer` interface (`decompose(goal, ctx) → Promise<SubtaskDraft[]>`), `heuristicDecomposer` / `decomposeOffline` (FR/EN templates: launch, MVP, video, podcast, article, presentation, event, moving, trip; then leading-verb plans; then a generic plan), `withFallback(aiProvider)` (sanitizes provider output, falls back offline), `sanitizeDrafts`, `scaleToBudget`, `subtaskRecords(drafts, { parent })`. Draft `dependsOn` holds indices of earlier drafts only, so drafts are acyclic by construction. |
| 2.3 Decay         | `decay(task, prefs, now) → { level 0..1, state }` (max of postponement and age signals; age ignored while planned ahead), `postponePatch(task, toDay)`.                                                                                                                                                                                                                                                                                                                                                             |
| 2.4 Eisenhower    | `quadrant(task, now, opts?)`, `matrix(tasks, now)`, `isUrgent`, `isImportant`, `quadrantPatch(task, target, now)` for drag and drop.                                                                                                                                                                                                                                                                                                                                                                                |
| 2.6 Pomodoro      | `pomodoroPlan(estimateMin, opts)`, `logTimePatch(task, log)` (idempotent), `focusMinutes(task, range?)`, `estimateAccuracy(tasks)`.                                                                                                                                                                                                                                                                                                                                                                                 |
| 2.8 Formulas      | `compileFormula(source, limits?)`, `evaluateFormula(source, scope)`, `evaluateTaskFormula(source, task)`, `taskScope(task)`. Hand-written tokenizer, Pratt parser and evaluator — no `eval`/`Function`, bounded length (1 000) and depth (64). Results: `{ ok: true, value } \| { ok: false, code, error, position }`.                                                                                                                                                                                              |
| 2.12 Kanban       | `toBoard(tasks, groupBy, opts)` (status, priority, mode, tag, project, quadrant — stable columns), `hierarchyBoard(tasks, rootId?)`, `moveCardPatch(task, toColumn, groupBy, opts)`, `subtaskProgress`.                                                                                                                                                                                                                                                                                                             |
| 2.15 WIP limit    | `wipStatus(tasks, day, prefs, timeZone)`, `canAddPriorityTask(...) → { allowed, status, reason? }`, `wipReasonText(reason, locale)` — rationale: Cowan (2001), working memory holds about four chunks.                                                                                                                                                                                                                                                                                                              |

## Formula language

Numbers, strings (`"…"` or `'…'`), `true`/`false`; `+ - * / % ^` (right-associative `^`,
`-2 ^ 2 = -4`), comparisons `== != < <= > >=` (`=` and `<>` accepted), `&& || !` with
short-circuit; identifiers from task fields (`title`, `status`, `priority`, `mode`, `energy`,
`estimateMin`, `postponedCount`, `focusMin`, `done`, `important`) and custom `fields`
(`[Name with spaces]`); functions `min max round ceil floor abs if hours`. Types are strict:
only `+` concatenates strings.

Tests: `cd packages/core && npx vitest run src/tasks`.
